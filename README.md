# 🌐 Developer Portfolio

A modern and fully responsive developer portfolio built using **React.js**, **Vite**, and **Tailwind CSS**. The portfolio is designed to showcase projects, technical skills, and development experience through a clean user interface and scalable component-based architecture.

The application emphasizes modern frontend development practices, responsive design principles, reusable components, and optimized project organization.

---

## 🚀 Tech Stack

### Frontend

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)

### Tools & Technologies

* Git & GitHub
* Responsive Design
* Component-Based Architecture
* REST API Integration

---

## ✨ Features

* Modern and responsive user interface
* Smooth scrolling navigation
* Dynamic projects section
* Skills and technologies showcase
* Resume integration
* Professional contact section
* Reusable React components
* Mobile-friendly layout
